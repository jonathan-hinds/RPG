# Frost Shock VFX

This folder is generated by `Tools > RPG Clone > VFX > Build Frost Shock VFX`.

The package uses animated textured mesh volumes for its primary silhouette and the generated atlases for secondary particles, crack overlays, mist, snow, and breakup. Runtime gameplay remains owned by the existing ability and buff systems.

The generic ability VFX controller supplies caster, casting-hand anchors, target, and impact position. The projectile phase requests the impact when its receiver-local travel completes. The persistent slow phase watches the target's replicated `shaman_frost_shock` buff and exits when that buff is removed or expires; it never changes damage, movement speed, or authoritative timing. Remote observers use the same `PlayReplicatedAbilityReleased` and replicated `BuffApplied` paths as every other ability.

Re-run the builder after changing `FrostShockVFX_Default`. Use `Tools > RPG Clone > VFX > Validate Frost Shock VFX` to verify asset wiring and the mesh-first content rules.

## Package layout

- `FrostShockCastVFX`: standalone instant-hand phase for preview and reuse.
- `FrostShockProjectileVFX`: the wired release prefab; contains the hand snap plus a three-layer tapered mesh projectile.
- `FrostShockImpactVFX`: contact flash, textured mesh explosion volumes, radial mesh shards, rings, cracks, detached ground response, and the nested slow prefab.
- `FrostShockSlowDebuffVFX`: foot/ankle plates, shin and body overlays, rotating tube bands, sparse particles, movement trail, reactive pulses, and buff-driven progression.
- `FrostShockExpirationVFX`: reusable thaw/shatter content; the integrated slow prefab contains the same expiration language so it can finish without creating another network event.
- `FrostShockVFX`: complete package reference prefab.

## Spatial behavior

Projectile trail, impact fragments, snow, mist, movement traces, and expiration particles use world-space simulation. The short ground-frost root detaches at initialization and self-cleans. Hand volumes stay on the resolved casting origin; the slow mesh volumes remain target-attached.

## Art workflow

Primary silhouettes use generated low-poly mesh assets with shared scrolling/dissolving URP materials. Atlases add sprite-sheet variation for bursts, cracks, snow, mist, and fragments. Tune counts, scales, colors, brightness, duration presentation, and quality from `Profiles/FrostShockVFX_Default.asset`; gameplay duration remains sourced from the active buff.

The high-frequency cast/projectile prefab opts into the shared `MMOAbilityVfxPool`; it is retained only after its world-space trails have finished. Other ability prefabs remain unchanged unless they explicitly add `MMOAbilityVfxPoolable`.
