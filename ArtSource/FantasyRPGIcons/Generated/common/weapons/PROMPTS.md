## Shared direction

Create an original, borderless, square 1024x1024 Common-rarity fantasy MMORPG inventory icon. Match the approved project's chunky hand-painted brush language, broad value groups, saturated material separation, simplified materials, and soft vignette without copying an existing object or composition. Show one weapon in a strong diagonal three-quarter crop. Keep all silhouette-defining ends inside a central 80-84% safe area so the existing Unity slot border cannot crop important details, while painted atmosphere still reaches every canvas edge. Design backward from 32x32 readability with one dominant silhouette, limited micro-detail, selective highlights, and a quiet abstract background. No character, text, logo, watermark, photorealism, PBR product rendering, full scene, baked UI frame, metallic rim, bevel, hard rectangle, or rarity outline.
