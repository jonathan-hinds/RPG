# Fantasy RPG Icon Generator

A reusable Skill for generating compact, original, classic-MMORPG-style icon artwork.

The package includes:

- A positive inventory-interface reference and a rejected over-rendered reference.
- Item rarity art direction from poor through legendary.
- Templates for items, abilities, buffs, and debuffs.
- A quality checklist focused on 32x32 readability.
- An export script that automatically organizes results by rarity and category.


## Artwork edge treatment

Generated icons must have no baked frame or border. Artwork should extend to the canvas edges and finish with a soft irregular painted vignette. Apply inventory-slot and rarity borders separately in Unity.
